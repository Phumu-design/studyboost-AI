# StudyBoost AI - Responsive Web Prototype

A fully responsive, front-end-only website prototype for **StudyBoost AI**, a student-focused startup concept. This project was built as a portfolio piece to demonstrate modern, standards-compliant HTML and CSS practices, with a strong focus on responsive layout and creative user experience.

## 🚀 Live Demo
You can view the live site here: [https://phumu-design.github.io/studyboost-AI/](https://phumu-design.github.io/studyboost-AI/) *(Note: You need to enable GitHub Pages in Settings for this to work)*

## ✨ Features
*   **Fully Responsive:** Tested and optimised for desktop, tablet, and mobile breakpoints.
*   **Pure CSS Navigation:** A hamburger menu on mobile built without JavaScript using the CSS checkbox hack.
*   **Space-Themed Aesthetic:** A calming soft blue and lilac colour palette.
*   **CSS-Only Illustrations:** The astronaut, rockets, and speech bubbles are all built entirely with CSS shapes and animations (no images).
*   **Semantic HTML:** Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` for accessibility and structure.
*   **Interactive Elements:** Smooth transitions on buttons, nav links, and form inputs, as well as a simulated rocket launch animation.

## 🛠️ Technologies Used
*   **HTML5** (Semantic structure)
*   **CSS3** (CSS Grid, Flexbox, Custom Properties, Transitions, Animations)
*   **No frameworks, no JavaScript** (as per project brief)

## 📂 Project Structure
*   `index.html` - Home page with hero section, astronaut, and mission statement.
*   `features.html` - Overview of the AI features, with the astronaut peeking out to "explain" each one.
*   `motivation.html` - Motivational quotes with "Train AI" buttons and a quote submission form.
*   `styles.css` - All styling, responsive media queries, and CSS animations.
